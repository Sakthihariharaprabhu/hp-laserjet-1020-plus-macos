## What this is

Experimental Apple Silicon macOS test candidate for HP LaserJet 1020 / 1020 Plus USB printing. This is a request for limited, supervised testing—not a stable release or a claim of confirmed compatibility.

## Build provenance

- Workflow: [Build macOS candidate](https://github.com/Sakthihariharaprabhu/hp-laserjet-1020-plus-macos/actions/runs/40209197664)

- CI result: success; source/bundle checks and conversion-pipeline smoke test passed.
- Platform: Apple Silicon ARM64 hosted macOS runner.
- Package: unsigned and not notarized.
- Physical printing: not yet verified.

The Actions ZIP generated by that run had SHA-256 `237b441377a433d22001d81c432c82734aab0b68b53299787ccbd8a86bffe9c4`. This is the ZIP checksum only; it is **not** the package checksum. Replace/update provenance if a newer artifact is attached.

## Known limitations and cautions

- The installer, CUPS/USB behavior, GUI firmware setup, LaunchDaemon, power-cycle flow and recovery/uninstall behavior have not yet been physically validated.
- Firmware is not bundled. The GUI offers a local-file path and a checksum-verified download/convert path using a community mirror referenced by OpenPrinting; it is not an official HP download source. Checksum validation does not resolve firmware licensing or provenance concerns.
- macOS security may block an unsigned, non-notarized package. Do not disable Gatekeeper or SIP. Stop if macOS reports malware or damage.
- No warranty or support from HP is implied. This is an independent community project, not affiliated with or endorsed by HP.
